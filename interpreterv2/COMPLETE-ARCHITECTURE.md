## SQLite Schema

```sql
-- Core definitions (source of truth)
CREATE TABLE definitions (
    content_hash TEXT PRIMARY KEY,      -- SHA3-512 hash (128 hex chars)
    name TEXT NOT NULL,                 -- Human-readable name
    kind TEXT NOT NULL,                 -- 'function', 'type', 'ability', 'effect', 'impl'
    module_path TEXT NOT NULL,          -- 'std::list', 'main', etc.
    serialized_ast BLOB NOT NULL,       -- Normalized AST (for recompilation)
    type_info BLOB,                     -- Serialized type information
    created_at INTEGER NOT NULL,        -- Unix timestamp
    source_location TEXT                -- Original file:line for debugging
);

CREATE INDEX idx_definitions_name ON definitions(name);
CREATE INDEX idx_definitions_module ON definitions(module_path);

-- Name to current hash mapping (for hot reload)
CREATE TABLE name_mappings (
    module_path TEXT NOT NULL,
    name TEXT NOT NULL,
    current_hash TEXT NOT NULL REFERENCES definitions(content_hash),
    PRIMARY KEY (module_path, name)
);

-- Dependency graph
CREATE TABLE dependencies (
    from_hash TEXT NOT NULL REFERENCES definitions(content_hash),
    to_hash TEXT NOT NULL REFERENCES definitions(content_hash),
    dependency_kind TEXT NOT NULL,      -- 'calls', 'uses_type', 'implements', 'handles'
    PRIMARY KEY (from_hash, to_hash)
);

CREATE INDEX idx_dependencies_to ON dependencies(to_hash);

-- Compiled code cache
CREATE TABLE compiled_cache (
    content_hash TEXT PRIMARY KEY REFERENCES definitions(content_hash),
    serialized_nodes BLOB,              -- Serialized Truffle node tree (if possible)
    type_profile BLOB,                  -- Observed type profile from execution
    frame_descriptor BLOB,              -- Serialized FrameDescriptor
    compilation_tier INTEGER DEFAULT 0, -- 0=never, 1=interpreted, 2=compiled
    execution_count INTEGER DEFAULT 0,  -- How many times executed
    last_executed_at INTEGER,           -- Unix timestamp
    jit_compiled_at INTEGER             -- When JIT compilation happened
);

-- Version history (for rollback)
CREATE TABLE version_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    module_path TEXT NOT NULL,
    name TEXT NOT NULL,
    old_hash TEXT,
    new_hash TEXT NOT NULL,
    changed_at INTEGER NOT NULL,
    change_type TEXT NOT NULL           -- 'create', 'update', 'delete'
);

CREATE INDEX idx_version_history_name ON version_history(module_path, name);

-- Worker registry (for distributed execution)
CREATE TABLE workers (
    worker_id TEXT PRIMARY KEY,
    endpoint TEXT NOT NULL,             -- 'grpc://worker1:50051'
    region TEXT,                        -- 'us-west', 'eu-central', etc.
    last_heartbeat INTEGER,
    cached_hashes TEXT                  -- JSON array of hashes this worker has
);
```

## Key Design Decisions

| Decision | Rationale |
|----------|-----------|
| **SQLite for persistence** | Already in codebase, battle-tested, supports in-memory mode |
| **Two-level cache (Memory + SQLite)** | Memory for hot path, SQLite for persistence |
| **Hash verification on fetch** | Trust-but-verify prevents code tampering |
| **Keep old hashes on update** | Enables rollback, supports in-flight requests |
| **Integer variant tags** | O(1) switch vs O(n) string compare |
| **Typed frame slots** | Primitives stay unboxed throughout execution |
| **DirectCallNode for abilities** | Inlines after JIT, no dispatch overhead |
| **Store type profiles in SQLite** | Zero warmup on restart |
