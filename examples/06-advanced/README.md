# Advanced - Complex Patterns and Real-World Examples

Advanced Funk programming techniques and real-world application patterns.

## Examples in this folder

### [calculator.funk](./calculator.funk)
Expression calculator with pattern matching.
- Recursive data structures
- Complex pattern matching
- Mathematical expressions

### [state-machine.funk](./state-machine.funk)
State machine implementation.
- State transitions
- Event handling
- Complex state logic

### [json-parser.funk](./json-parser.funk) *(Coming Soon)*
JSON parsing with variants and pattern matching.
- Recursive parsing
- Error handling
- Data transformation

### [web-server.funk](./web-server.funk) *(Coming Soon)*
Simple web server with effects.
- HTTP handling
- Request routing
- Response generation

## Key Concepts Covered

- **Complex Pattern Matching**: Deep nesting and guards
- **Recursive Data Structures**: Trees, lists, and graphs
- **State Management**: Complex state transitions
- **Error Handling**: Robust error recovery patterns
- **Performance**: Optimization techniques

## Running the Examples

```bash
funk-dev exec calculator.funk
funk-dev exec state-machine.funk
```
