# Basics - Language Fundamentals

Learn the core concepts of the Funk programming language through these fundamental examples.

## Examples in this folder

### [hello-world.funk](./hello-world.funk)
Your first Funk program - the classic "Hello, World!" example.
- Basic string literals
- Let bindings
- Program structure

### [variables.funk](./variables.funk)
Working with variables and different data types.
- String, integer, boolean, and float types
- Variable declarations
- Type inference

### [arithmetic.funk](./arithmetic.funk)
Basic arithmetic operations and expressions.
- Mathematical operators
- Expression evaluation
- Operator precedence

### [strings.funk](./strings.funk)
String manipulation and operations.
- String concatenation
- String literals
- Working with text

### [comments.funk](./comments.funk)
Different ways to document your code.
- Single-line comments
- Documentation comments
- Code organization

## Key Concepts Covered

- **Let bindings**: How to declare variables and values
- **Data types**: Basic types available in Funk
- **Expressions**: How expressions are evaluated
- **Comments**: Documenting your code
- **Program structure**: How Funk programs are organized

## Running the Examples

```bash
# Run any example
funk-dev exec hello-world.funk

# Check syntax
funk-dev check variables.funk
```
